# Unused and exploratory CNN experiments (historical archive)

These five Python scripts came from the project author's original folder **"codes i didint use"**. They are preserved to document development attempts, troubleshooting, and alternative architectures. **They must not be confused with the final evaluated CNN scripts** in [../final_cnn/](../final_cnn/).

| Script | Notes confirmed from the source |
| --- | --- |
| [Classification_version1.py](Classification_version1.py) | Early CNN experiment pointed only to Marvel-specific folders, not the complete two-class dataset |
| [Classification_version2.py](Classification_version2.py) | Similar early prototype with a data-batch inspection step |
| [Classification_version4_epoch15_really 11 layer.py](Classification_version4_epoch15_really%2011%20layer.py) | An experimental 11-layer network trained for 15 epochs |
| [Classification_version4_epoch17.py](Classification_version4_epoch17.py) | Experimental script whose code actually specifies **18 epochs**, despite the filename |
| [Classification_version4_epoch20_repeat.py](Classification_version4_epoch20_repeat.py) | Another exploratory script that also specifies **18 epochs** in the code, despite the filename |

The original scripts' machine-specific paths have been anonymized with `REPLACE_WITH_PROJECT_ROOT`. They have otherwise been retained as historical source material, **not edited to be a clean reproducible pipeline**.

For the final 2024 model versions and the five non-CNN comparison methods, see the [historical source index](../README.md).
